## Preguntas de autoevaluación

### ¿Qué sucede si se usa text/plain en lugar de text/html?
El navegador muestra el código HTML como texto y no interpreta las etiquetas.

### ¿Qué debe hacer el servidor si se solicita una ruta inexistente?
Debe responder con el código de estado 404 e informar que el recurso no fue encontrado.

### ¿Qué ocurre al utilizar un puerto inferior a 1024 en Unix o WSL2?
Normalmente se necesitan privilegios de administrador porque esos puertos están reservados para procesos con permisos elevados.
